The problem

Codebases are unread

Large repos are opaque — onboarding means scrolling files, guessing architecture, and pinging teammates. Codrix makes a repo explain itself.

The approach

Grounded answers, streamed live

Exponential backoff on Bedrock calls, automatic Groq LLaMA fallback, and Server-Sent Events so long agent runs stay transparent — never a frozen spinner.

Why it's interesting

Diagrams from live code

A Prompt-to-Diagram engine renders Architecture, UML Sequence, and ER views from the actual codebase — then refines them in plain English.
